# SRAM in CMOS vs FinFET for AI Applications - Design Documentation

## Project Overview
This project contains comprehensive design and simulation results for 6-transistor (6T) and 1-bit SRAM implementations comparing traditional CMOS and FinFET technologies for AI applications.

## Directory Structure

### Schematics/
Contains detailed circuit diagrams and schematic designs for all major components:
- 1-bit SRAM Cell
- 6T-SRAM Array
- Sense Amplifier
- Pre-charge Circuit
- Write Driver
- Decoder

### Results/
Contains simulation results and transient response analyses:
- Timing diagrams
- Signal waveforms
- Performance metrics
- Transient response measurements

## Key Components

1. **1-bit SRAM Cell** - Basic storage element
2. **Sense Amplifier** - Differential signal detection
3. **Pre-charge Circuit** - Bit line equalization
4. **Write Driver** - Data writing mechanism
5. **Decoder** - Address selection
6. **6T-SRAM Array** - Multi-cell storage array

## Simulation Tools
- Cadence Virtuoso Analog Design Environment
- Cadence Visualization & Analysis XL
- GPDK090 CMOS Process Kit

## Performance Analysis
All components have been characterized with:
- Transient response analysis
- Timing measurements
- Signal integrity verification
- Multi-cycle operation validation
