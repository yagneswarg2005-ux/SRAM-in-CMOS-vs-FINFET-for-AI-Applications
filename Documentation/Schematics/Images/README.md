# Schematic Images

This directory contains all schematic circuit diagrams for the SRAM design.

## Image Files

1. **1bit_SRAM_schematic.png** - 1-bit SRAM Block Diagram
   - Complete architecture showing all interconnected blocks
   - Signal flow and connectivity

2. **FINFT_1bit_sram_schematic.png** - FinFET 1-bit SRAM Cell
   - Transistor-level schematic using FinFET technology
   - Cross-coupled latch topology

3. **FINFT_Sense_ampl_schematic.png** - Sense Amplifier Circuit
   - Differential amplifier for bit line sensing
   - Latch-based design

4. **FINFT_Pre_charge_schematic.png** - Pre-charge Circuit
   - Bit line initialization circuit
   - PMOS pull-up network

5. **6T_SRAM_SRAM_ARRAY_schematic.png** - 6T SRAM Array
   - Multi-cell array architecture (4x4)
   - Word lines, bit lines, and pre-charge circuits

6. **6T_SRAM_precharge_schematic.png** - Pre-charge Circuit (Detailed)
   - Detailed implementation with transistor specifications
   - Two PMOS transistor configuration

7. **6T_SRAM_Sense_ampl_schematic.png** - Sense Amplifier and Write Driver
   - Complete sensing and write functionality
   - Latch-based differential amplifier
